# Rules

Meta-rules in `Rules-of-Rules.md`. Two rule documents today, both flat
at this level: `dev-environment-rules.md` (prefix `env`) — tooling/
process rules, established via greenfield instantiation before any
product code existed — and `catalyst-core-rules.md` (prefix `core`) —
product behavior rules for `packages/catalyst-core`, opened once real
application work started (`INSTANTIATION-GUIDE.md` §3 step 5).
`templates/TEMPLATE-RULE-v1.md` is the only template file allowed at
this root. `rules.md` is the global index — every rule ID must appear
there (`Rules-of-Rules.md` §5).
