# Analyses

Four-eyes analyses of existing code (`ANALYSIS-NNNNNN`): each record holds
the scope, mode and commit analysed, two independent passes, their
reconciliation and the user's decision on every domain, rule and defect
found (`ANALYSIS-PLAYBOOK.md`, `/run-analysis`, `catalyst analysis`).
Reports live in `reports/<ID>/`. See [`analyses.md`](analyses.md) for the
index and [`templates/`](templates/) for the versioned template.
